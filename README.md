# РГР №2 по математической статистике

Проект выполняет полный статистический анализ данных варианта `A-1` и сохраняет результаты в виде консольного отчёта, графиков и артефактов для LaTeX-отчёта.

## Структура

- `main.py` — точка входа.
- `src/analysis.py` — чтение данных, статистические критерии, графики и сохранение артефактов.
- `resources/RGR2_A-1_X1-X4.csv` — входные данные.
- `figures/` — графики, создаются автоматически.
- `artifacts/` — таблицы и JSON с результатами, создаются автоматически.
- `report.tex` — готовый LaTeX-отчёт.

## Запуск

1. Синхронизировать окружение:

```bash
uv sync
```

2. Выполнить анализ:

```bash
uv run python main.py
```

Если зависимости уже установлены в активное окружение, можно запускать и напрямую:

```bash
python main.py
```

После запуска будут созданы:

- `figures/*.png`
- `artifacts/descriptive_statistics.csv`
- `artifacts/x4_pearson_intervals.csv`
- `artifacts/results.json`

## Сборка отчёта

После выполнения `python main.py` отчёт можно скомпилировать командой:

```bash
pdflatex report.tex
```

Отчёт использует готовые графики из `figures/`, поэтому перед компиляцией нужно сначала выполнить `uv run python main.py`.
